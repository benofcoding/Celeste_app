  • Timing is done using the in-game timer, please refrain from taking long breaks mid-run.

  • Entering a level in another save file during the run is banned.

  • Altering any game files except for settings.celeste is banned. In particular, runs done on Everest are not allowed.
  • You can restart into vanilla Celeste by holding right on the title screen.
  • The use of any third-party programs that directly affect the game are banned, with the exception of keyboard rebinders, controller mappers, and autosplitters.
